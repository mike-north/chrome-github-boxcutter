## Description

GitHub Boxcutter is a Chrome extension that enhances package manifests on GitHub. Click on package names to jump directly to their repositories for seamless navigation.

### Features

- **Clickable Package Links** - Jump to package repositories with one click
- **Multi-Package Manager Support** - Works with NPM, Bower, Gem, Hex, and more

## Install

### Chrome Web Store

[Download from Chrome Web Store](https://chromewebstore.google.com/detail/github-boxcutter/knapnimomamjogbajmmoefhopnebjbff)

### From Source

```bash
# Clone the repository
git clone https://github.com/theluckystrike/chrome-github-boxcutter.git
cd chrome-github-boxcutter

# Load unpacked extension in Chrome
# 1. Open chrome://extensions
# 2. Enable "Developer mode"
# 3. Click "Load unpacked"
# 4. Select the extension directory
```

## Usage

Once installed, GitHub Boxcutter automatically enhances package manifests on GitHub:

1. Visit any repository with a `package.json`, `Gemfile`, `bower.json`, or `hex.toml`
2. Package names become clickable links
3. Click to navigate directly to the package repository

## Supported Package Managers

- NPM (JavaScript)
- Bower (JavaScript)
- Gem (Ruby)
- Hex (Elixir)
